# splify2_fork

Форк [xyzmean/splify2](https://github.com/xyzmean/splify2), основанный на релизе **26.9.2 Andromeda** (4dc8927). Интерфейс для OpenWrt с фиолетовым акцентом, прозрачными стеклянными поверхностями и элементами Material 3 Expressive.

## Интерфейс

- **Обзор:** живой статус подключения, число устройств и время работы; предупреждение с подсказкой и переходом в диагностику; правила с галочками, редактированием и исходными счётчиками трафика; выходы, сгруппированные по подпискам.
- **Проверка маршрута:** пресеты youtube.com, instagram.com, discord.com, ru-tracker.org и ozon.ru. Ответ берётся из steer explain, а не вычисляется по настройкам браузером.
- **Правила:** оригинальный редактор, каталог сервисов и свои списки.
- **Подключения:** источники (подписки, туннели, XSTEER), выходы VPN и исходный DoH.
- **Zapret:** самостоятельный раздел с установкой, стратегиями и проверками из оригинала.
- **Настройки:** целиком кликабельные строки, архив настроек внизу без отдельного экрана.

## Разработка

Требуется Node.js 22 или новее.

```sh
cd ui
npm ci
npm run dev
npm test
npm run build
```

Без LuCI обычный dev-сервер не имеет доступа к роутеру; RPC-контракт сохранён. Стили привязаны к .sp-root и не меняют оформление остального LuCI. Светлая и тёмная темы поддерживаются; при отсутствии backdrop-filter поверхности становятся непрозрачными.

## Пакет OpenWrt

Сборка пакета производится исходным build.sh в Linux. Код ориентирован на движок steer схемы v1, как релиз 26.9.2; совместимость с Bode/steer 2.0 здесь не заявлена. На живом роутере этот форк пока не проверен.

Установщик и самообновление интерфейса направлены на vnenapravo7-source/splify2_fork. До публикации собственного релиза готовые пакеты там отсутствуют. Движок, каталог и сторонние модули продолжают использовать исходные источники. Перед установкой сохраните архив настроек.

Исходная документация: [docs/UPSTREAM_README.md](docs/UPSTREAM_README.md). История разработки оригинала сохранена.
