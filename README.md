# splify2_fork

Форк [xyzmean/splify2](https://github.com/xyzmean/splify2), основанный на релизе **26.9.2 Andromeda** (4dc8927). Интерфейс для OpenWrt с фиолетовым акцентом, прозрачными стеклянными поверхностями и элементами Material 3 Expressive.

## Интерфейс

Основные разделы находятся в верхней панели и на компьютере, и на телефоне.

- **Обзор:** живой статус подключения, число устройств и время работы; предупреждение с подсказкой и переходом в диагностику; правила с галочками, редактированием и исходными счётчиками трафика; выходы, сгруппированные по подпискам.
- **Проверка маршрута:** пресеты youtube.com, instagram.com, discord.com, ru-tracker.org и ozon.ru. Ответ берётся из steer explain, а не вычисляется по настройкам браузером.
- **Правила:** оригинальный редактор, каталог сервисов и свои списки. Автообновление: каждые 12 часов, 1, 2, 3 дня или неделю. Обновляются используемые списки каталога и все свои списки по ссылкам; ручные записи и файлы сохраняются. Интервал хранится в UCI, задание работает без открытого браузера. При ошибке скачивания остаётся прежний список.
- **Подключения:** раскрывающиеся блоки подписок, туннелей, XSTEER и DoH; выходы VPN под разделительной линией на этой же странице.
- **Zapret:** самостоятельный раздел с установкой, стратегиями и проверками из оригинала.
- **Настройки:** целиком кликабельные строки, архив настроек внизу без отдельного экрана.

## Разработка

Требуется Node.js 22 или новее.

```sh
cd ui
npm ci
npm run dev
npm test
npm run build
```

Без LuCI обычный dev-сервер не имеет доступа к роутеру; RPC-контракт сохранён. Стили привязаны к .sp-root и не меняют оформление остального LuCI. Светлая и тёмная темы поддерживаются; при отсутствии backdrop-filter поверхности становятся непрозрачными.

## Пакет OpenWrt

Сборка пакета производится исходным build.sh в Linux. Код ориентирован на движок steer схемы v1, как релиз 26.9.2; совместимость с Bode/steer 2.0 здесь не заявлена. На живом роутере этот форк пока не проверен.

Установщик и самообновление интерфейса направлены на vnenapravo7-source/splify2_fork. Готовые пакеты доступны в [релизе 26.9.4 Glass Expressive](https://github.com/vnenapravo7-source/splify2_fork/releases/tag/v26.9.4). Движок, каталог и сторонние модули продолжают использовать исходные источники. Перед установкой сохраните архив настроек.

Исходная документация: [docs/UPSTREAM_README.md](docs/UPSTREAM_README.md). История разработки оригинала сохранена.

## Установка и выбор движка

Выполните по SSH на роутере:

```sh
wget -O /tmp/splify2-install.sh https://raw.githubusercontent.com/vnenapravo7-source/splify2_fork/v26.9.4/install.sh && sh /tmp/splify2-install.sh
```

Установщик определяет apk/opkg и архитектуру сам. Для ручной установки скачайте файл `.apk` для apk или `.ipk` для opkg из релиза.

Нужен OpenWrt 22.03 или новее и от 2 МБ свободного флеша. Исторический ориентир для steer 1.3.0: движок 112–299 КБ, пакет 112–127 КБ в базовом варианте и 263–299 КБ в расширенном. Точные размеры текущих пакетов указаны в релизе steer.

| Вариант | Назначение | Размер в steer 1.3.0 |
|---|---|---|
| Расширенный (`steer-extended`) | Встроенный клиент VLESS/Reality | 263–299 КБ |
| Базовый (`steer`) | Готовый WireGuard/AmneziaWG или другой туннель | 112–127 КБ |

Выбор не окончательный: сменить вариант можно в Настройки → О ПО, в карточке движка.

Если на роутере стоит splify первой версии, установщик обнаруживает её службы и наборы в таблице `inet fw4` и сообщает о конфликте. Сам он их не удаляет и настройки не переносит. Остановите первую версию перед включением маршрутизации splify2.

## Отчёт о работе

**splify2 раз в час отправляет короткий обезличенный отчёт о своей работе, и это включено по
умолчанию: пользуясь splify2, вы соглашаетесь на сбор данных, нужных для разработки.** Выключить
отправку можно в интерфейсе: **Настройки → О ПО**, карточка «Отчёт о работе».

Отчётом видно то, чего иначе не увидеть никак: сколько роутеров работает, какие на них версии,
и когда у людей что-то начинает сыпаться — целиком или в одной стране у одного провайдера.

**Уезжает:** модель роутера и версия OpenWrt, версии splify2 и движка, страна, город и номер
автономной системы, виды выходов и подняты ли они, номера списков каталога, состояние DoH и
обхода DPI, домен панели подписки (только две последние метки), номера сработавших проверок,
счётчики событий с загрузки и структурный факт падения.

**Не уезжает никогда:** ни одного IP-адреса, ссылок подписок и токенов в них, названий
подписок, имён узлов и их адресов, имён выходов и правил, имён своих списков, ключей туннелей,
**строк журнала и текстов ошибок — в том числе при падении**, счётчиков трафика и числа
устройств в сети.

Что именно уедет с ВАШЕГО роутера, можно посмотреть до отправки: в той же карточке — кнопка
**«Показать пакет»**. Полный контракт — [docs/TELEMETRY.md](docs/TELEMETRY.md).
